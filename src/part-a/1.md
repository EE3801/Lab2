## 8.
Python usually uses a "site-packages" directory to store all installed packages and libraries. So when you install a module, you will typically do "pip install .", which copies code to the site-packages directory (e.g. `~/miniforge3/envs/aws/lib/python3.12/site-packages/`). 
However, we will link the forked PyHipp repository on your computer to the site-packages directory instead by doing "pip install -e ." so that you can edit and test your code more quickly instead of having to install it into the site-packages directory each time you change some code (replace the directory path below with the appropriate directory for your computer):

```shell
(aws) $ cd ~/Documents/EE3801/DataProcessingTools

(aws) $ pip install -e .

(aws) $ cd ../PanGUI

(aws) $ pip install -e .

(aws) $ cd ../PyHipp

(aws) $ pip install -e .
```

> <p class="note"> Note
>
> Make sure that when you go up a directory with the command:
> ```shell
> (aws) $ cd ..
> ```
> your `PanGUI` and `PyHipp` folders must exist in the same parent folder as your DataProcessingTools. In the example below, that would be the `Documents/EE3801` folder or else your command will fail.

> <p class="note"> Note 
>
>You can type part of the command, e.g. 
>
> ```shell
> cd ~/Doc
> ```
>
> and then hit the "Tab" key, where auto-complete will type the rest of "Documents" if it is the only directory or file with those first few letters.

## 10.
You are now ready to run the Python packages you installed using ipython:
```shell
(aws) $ ipython
```

which should give you the following prompt:
```shell
In[ ]: 
```

Do the following to test the PyHipp and DataProcessingTools modules:

```shell
In[ ]: import PyHipp as pyh
```

You may receive the following warning, but it is safe to ignore it:

```shell
/Users/shihcheng/Documents/Work/Python/PyHipp/PyHipp/eyelink.py:5: UserWarning: Eyelink import failed. You won't be able to read edf files
  warnings.warn("Eyelink import failed. You won't be able to read edf files")
```

Note that commands preceded by `In[ ]:` means you should be typing the commands in the ipython terminal.

You can test that PyHipp was installed properly by doing the following:

```shell
In[ ]: pyh.pyhcheck('hello')
```

which should return:

```shell
hello
```
This means that PyHipp has been installed successfully.
